## 💻 Sobre o projeto

Este aplicativo mobile foi desenvolvido em **React Native** utilizando **Expo Router** para navegação.  
O sistema permite visualizar cursos, acessar detalhes e realizar inscrição, simulando um ambiente simples de plataforma EAD.

O objetivo principal é praticar conceitos de desenvolvimento Mobile, navegação entre telas, animações com a API do React Native e componentização.

---

## 🚀 Tecnologias utilizadas

- **React Native**
- **Expo**
- **Expo Router / React Navigation**
- **JavaScript**

---

## 📱 Funcionalidades do App

### 🏠 Home
- Exibe a lista de cursos disponíveis.
- Cada curso contém título, descrição e botão para detalhes.

### 📘 Tela de Detalhes
- Mostra informações completas sobre o curso selecionado.
- Inclui imagem, carga horária, descrição aprofundada e valor.

### 📝 Tela de Inscrição
- Formulário para simular inscrição no curso.
- Envia dados do usuário (nome, e-mail etc.).
- Exibe confirmação de inscrição.

---

## 🧭 Estrutura de Navegação

A navegação é feita com **Stack Navigation**, chamando as seguintes telas:

- `Home`
- `Detalhes`
- `Inscricao`
